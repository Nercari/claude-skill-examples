# Meeting notes to summary (fictional Quillmere Plumbing)
Output exactly these four sections, in this order, as Markdown H2 headings:
## Summary
(1-2 sentences)
## Decisions
(bullets; write "- None recorded" if none)
## Action items
Each line: `- [Owner] task (due: DATE)`. Use only owners and dates in the notes. If the owner or date is missing write `[CONFIRM]` in its place.
## Open questions
(bullets; "- None" if none)
Rules: never invent names, dates or numbers; max 200 words; no other sections, no preamble, no closing remarks.
