Velocrank Cycle Works: custom Claude skills, demonstrated

Velocrank Cycle Works is a made-up bike repair shop. Nercari built Claude skills that write price quotes and customer updates from the shop's own price list.

Measured results (demo runs, reproducible)

  • Without the skill: 0 of 5 outputs correct. With it: 5 of 5, on both skills tested.
